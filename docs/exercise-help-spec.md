# Постановка на доработку: Справка по упражнению

## Цель
Дать пользователю возможность быстро прочитать «как правильно делать упражнение»
прямо в момент перехода к нему — не выходя из тренировки и не отвлекаясь на внешние
ресурсы. Особенно важно для утренней зарядки: техника и безопасность (колени,
поясница) под рукой.

## Контекст
Программа состоит из упражнений (`Exercise`) с полями `name` и коротким `description`.
Короткого описания недостаточно, чтобы понять технику. Нужна развёрнутая справка
в едином формате.

## Формат справки (для каждого упражнения)
Шесть коротких блоков:
1. **Исходное положение**
2. **Как делать**
3. **Дыхание**
4. **Частые ошибки**
5. **Если тяжело** (регрессия / упрощение)
6. **Зачем** (какие мышцы / для чего)

## Объём (scope)
- Справки для всех основных упражнений программы v3 (17 уникальных движений).
- Точки вызова:
  - **Экран превью тренировки** (`WorkoutRunner`) — иконка «?» в карточке каждого
    упражнения в списках Preparation / Main / Cool Down.
  - **Активный экран упражнения** (`TimerDisplay`) — кнопка «Как делать» под названием
    текущего упражнения (показывается, когда идёт работа, а не отдых).
- Всплывающая карточка (bottom-sheet): затемнение фона, закрытие по тапу вне карточки,
  по кнопке «✕» и по Escape.
- Кнопка вызова показывается только если для упражнения есть справка; иначе — тихо
  скрыта (fallback на короткое `description`, если справку открыли программно).

## Вне объёма (non-goals)
- Видео и картинки (пока только текст).
- Справки для разминочных/заминочных упражнений сверх тех, что уже есть.
- Автопауза таймера при открытии справки на активном экране — отложено (см. ниже).
- Редактирование справок из интерфейса.

## Модель данных
- Источник для приложения: `lib/exerciseGuide.ts` — `Record<string, ExerciseGuide>`,
  ключ = точное `name` упражнения из программы. Одно движение может иметь несколько
  ключей-синонимов (напр. «Отжимания» и «Отжимания от пола» → один объект).
- Человекочитаемый источник: `docs/exercise-guide.md`.
- **Правило синхронизации:** при изменении текста правим оба файла. `docs/exercise-guide.md`
  — канонический текст, `lib/exerciseGuide.ts` — его отражение для рантайма.

## Затронутые файлы
- `lib/exerciseGuide.ts` — данные + `getExerciseGuide(name)`.
- `components/ExerciseHelpSheet.tsx` — компонент карточки-справки.
- `app/(app)/workout/[id]/WorkoutRunner.tsx` — «?» в превью-списке.
- `components/timer/TimerDisplay.tsx` — кнопка «Как делать» на активном экране.
- `docs/exercise-guide.md` — тексты справок.

## Критерии приёмки
- [x] У каждого основного упражнения v3 есть справка из 6 блоков.
- [x] На превью-экране у карточки с доступной справкой видна иконка «?»; тап открывает карточку.
- [x] На активном экране во время работы видна кнопка «Как делать»; тап открывает карточку.
- [x] Карточка закрывается тапом по фону, кнопкой «✕» и клавишей Escape.
- [x] Если справки нет — кнопка вызова не показывается (нет пустых карточек).
- [x] `npx tsc --noEmit` проходит без новых ошибок; eslint не добавляет новых замечаний.
